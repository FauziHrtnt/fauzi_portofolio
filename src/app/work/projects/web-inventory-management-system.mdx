## Overview Projek (Magang Industri)

Merancang dan mengimplementasikan sistem manajemen inventaris berbasis web terpusat beserta backend RESTful API yang berdiri sendiri menggunakan **PHP CodeIgniter 3 (CI3)** dan **MySQL** untuk PT. Indo Techno Medic.

---

## Pencapaian & Fitur Utama

- **Pelacakan Aset Perusahaan**: Mengelola lebih dari 50 aset fisik perusahaan (termasuk kendaraan operasional, laptop, dan perangkat elektronik kantor).
- **Perancangan Skema Database (ERD)**: Merumuskan skema database relasional yang dioptimalkan untuk mengelola data master (aset, kredensial pegawai, lokasi, dan log riwayat layanan).
- **Peningkatan Efisiensi 30%**: Merumuskan alur pengguna (*user flow*) yang intuitif dari tahap analisis kebutuhan awal hingga implementasi akhir, sehingga meningkatkan efisiensi pencatatan aset sebesar 30%.
- **RESTful API & Sinkronisasi Seluler**: Membangun modul administrasi web dan menangani permintaan sinkronisasi data dari aplikasi klien seluler.
- **Standar Keamanan Kode**: Memastikan kelancaran integrasi di seluruh modul aplikasi agar mematuhi protokol keamanan perusahaan dan standar struktur kode.

---

## Focus Areas & Tech Stack

- **Framework**: PHP CodeIgniter 3 (CI3)
- **Database**: MySQL (Relational Schema / ERD Design)
- **API Architecture**: RESTful API Development & JSON Synchronization
- **Administration**: Web System Administration & Asset Tracking

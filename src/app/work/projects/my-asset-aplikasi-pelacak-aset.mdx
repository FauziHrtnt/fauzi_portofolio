## Overview Projek (Tugas Akhir)

**My Asset** adalah aplikasi mobile native Android yang dikembangkan sebagai proyek Tugas Akhir untuk memodernisasi audit fisik aset dan manajemen pemeliharaan peralatan berbasis tiket secara real-time. Terintegrasi dengan database MySQL melalui RESTful API asinkron berformat JSON.

---

## Implementasi & Fitur Utama

- **Pemindaian QR Code Berbasis Kamera**: Mempercepat audit ruangan fisik (stok opname) dan verifikasi lokasi aset secara langsung di lapangan.
- **Pelacakan Pemeliharaan Berbasis Tiket (RBAC)**: Mekanisme Kontrol Akses Berbasis Peran (*Role-Based Access Control*). Pegawai dapat melaporkan kerusakan beserta lampiran foto dari kamera, sedangkan administrator memiliki akses penuh untuk menyetujui, menugaskan bengkel, dan mencatat pemeliharaan.
- **Ekspor Laporan PDF Lokal**: Mengintegrasikan `Android Download Manager API` untuk mengekspor dan menyimpan ringkasan aset berformat PDF langsung ke penyimpanan perangkat.
- **Integrasi RESTful API**: Mengomunikasikan aplikasi mobile dengan server database secara efisien.

---

## Focus Areas & Tech Stack

- **Platform**: Android Native (Java & Android SDK)
- **Backend & Database**: PHP RESTful API (JSON) & MySQL
- **Features**: QR Code Scanning, Role-Based Access Control (RBAC), Mobile UI Implementation
- **Tools & API**: Android Download Manager API (PDF Export)
